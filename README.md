h# FocusFlow AI — Full-Stack Application Project

## 1. Project Name

**FocusFlow AI — AI Study & Task Manager**

## 2. Problem

Students often have difficulty organizing assignments, deadlines, priorities, and study activities in one place.

## 3. Solution

FocusFlow AI provides a centralized web application where students can manage academic tasks, track completion, and monitor their progress through a simple dashboard.

## 4. Target Users

The primary target users are students who want a simple way to organize their academic tasks and study activities.

## 5. Main Features

* User authentication
* Dashboard
* Task management
* Task priorities
* Task completion
* Progress tracking
* Responsive interface
* Persistent data
* Modern student-focused UI

## 6. Technologies Used

* React
* Vite
* JavaScript
* CSS
* Supabase
* GitHub
* Vercel

## 7. Application Flow

```text
Landing Page
     ↓
Sign Up / Login
     ↓
Dashboard
     ↓
Create Task
     ↓
Manage Tasks
     ↓
Complete Tasks
     ↓
Track Progress
```

## 8. Database

Supabase was used to store application data and support authentication and user-specific data access.

## 9. Security

The application uses authentication and database access policies to help ensure that users can access their own data appropriately.

Sensitive credentials are not included in the public source code.

## 10. Testing

The application was tested for:

* Authentication
* Task creation
* Task completion
* Task deletion
* Data persistence
* Page refresh
* Navigation
* Responsive layout
* Basic error handling

## 11. Deployment

The application was deployed using Vercel.
